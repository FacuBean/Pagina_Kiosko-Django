Acerca de mí

Hola, soy Facundo Bustos Bean. Este es mi proyecto final: una aplicación web para la gestión de un kiosco.

La aplicación está diseñada para facilitar la administración de productos, ventas y clientes de un negocio. Su objetivo es brindar herramientas prácticas, accesibles y fáciles de usar para llevar el control del inventario y las transacciones diarias.

Funciones principales

  • ✅ Carga y visualización de productos disponibles.
  • ✅ Registro y consulta de ventas realizadas.
  • ✅ Administración de la información de los clientes.
  • ✅ Búsqueda rápida y eficiente de datos específicos.

Tambien cuenta con un sistema de autentificacion de usuarios y niveles de permisos, solo los administradores pueden acceder a las funciones mas sencibles
