Este projecto es una app web para gestionar productos,ventas y clientes de un kiosko. Desarollada en Django 5.2

# Estructura general

Tiene 4 apartados principales, con una cabecera de navegación para ir rápidamente al inicio, productos, ventas y clientes.

---

# Home

- Pantalla principal.
- Permite elegir a cuál de las 3 secciones ir:
  - Productos
  - Ventas
  - Clientes

---

# Productos

- Lista de productos disponibles.
- Botón para **agregar producto**.
- Botón para **buscar producto por nombre**.

---

# Ventas

- Lista de ventas registradas.
- Botón para **registrar nueva venta**.
- Botón para **buscar ventas**.

---

# Clientes

- Lista de clientes.
- Botón para **agregar cliente**.
- Botón para **buscar cliente por nombre**.
